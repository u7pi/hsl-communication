# 设备支持矩阵（私有维护版模板）

> 用途：记录你们团队在开源 v7.0.1 基线上的“实测可用性”，避免口口相传。

## 使用说明

- 每新增/修改一个协议适配，请至少更新一条矩阵记录。
- “状态”建议统一：`✅ 已验证` / `⚠️ 部分验证` / `❌ 不通过` / `🧪 待验证`。
- “验证版本”建议填写你们私有 tag，例如：`v7.0.1-custom.20260521.1`。

## 建议最小验证口径

每条“✅ 已验证”记录建议至少覆盖：

- 连接建立/断开。
- 单点读写（bit + word）。
- 批量读写（跨边界场景）。
- 连续运行 30 分钟稳定性。
- 异常恢复（设备重启/网络抖动）。

## 变更追溯

建议在每次状态变化时追加简短记录：
